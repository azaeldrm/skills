# Skills

A collection of my reusable skills for Codex, Opencode, and Claude Code, built around Spec-Driven Development (SSD) workflows, from planning and spec generation to implementation, bug auditing, and documentation.

## Skills

| Skill | Description |
|---|---|
| `explore-effort` | Run an interactive research session to produce a `STORY.md` before speccing a new effort |
| `spec-effort` | Interactively gather requirements and generate a `SPEC.md` for a new feature or app |
| `plan-tasks` | Generate a step-by-step `TASKS.md` implementation checklist from a spec |
| `step-task` | Implement the next incomplete step from `TASKS.md`, then stop to review |
| `implement-tasks` | Implement all remaining steps from `TASKS.md` sequentially without stopping |
| `finalize-effort` | Wrap up implementation, update docs, and open a pull request |
| `tasks-bugs` | Audit recent code for bugs and append confirmed findings to `BUGS.md` |
| `generate-state` | Snapshot the current state of the repository into `docs/STATE.md` |
| `generate-discovery` | Capture architectural decisions and discoveries into `DISCOVERY.md` |
| `review-changes` | Run 3 independent review sub-agents by default, verify findings against the code, and propose fixes before any edits |
